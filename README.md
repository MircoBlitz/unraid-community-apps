# MircoBlitz Unraid Community Applications

Community Applications templates maintained by MircoBlitz.

This repository is the single Community Applications index. It also owns Camofox's and NocoDB's Unraid documentation and template support, and Camofox's icon. Camofox and NocoDB use official upstream images; God's Eye View still needs its separate packaging repository until a suitable official image is available.

## Applications

| Application | Template | Documentation and support |
|---|---|---|
| Camofox Browser | [`templates/camofox-browser.xml`](templates/camofox-browser.xml) | [Installation and client setup](docs/camofox/README.md), [template support](https://github.com/MircoBlitz/unraid-community-apps/issues) |
| God's Eye View | [`templates/gods-eye-view.xml`](templates/gods-eye-view.xml) | [`MircoBlitz/gods-eye-view`](https://github.com/MircoBlitz/gods-eye-view) |
| NocoDB | [`templates/nocodb.xml`](templates/nocodb.xml) | [Installation and database setup](docs/nocodb/README.md), [template support](https://github.com/MircoBlitz/unraid-community-apps/issues) |

## Support

Use this repository's issue tracker for Camofox and NocoDB template/installation issues and shared Community Applications metadata. Report application defects to the relevant upstream project: [Camofox](https://github.com/jo-inc/camofox-browser/issues) or [NocoDB](https://github.com/nocodb/nocodb/issues). Use the God's Eye View packaging repository linked above for its installation, runtime and image issues.
